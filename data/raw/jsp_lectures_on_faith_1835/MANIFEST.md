# Joseph Smith Papers — "Lectures on Faith" (Doctrine and Covenants, Kirtland 1835, Part First "On the Doctrine of the Church", pp. [5]–64) and the 1835 D&C Preface

- **Document:** `doctrine-and-covenants-1835` on JSP (305 JSP pages). Only JSP pages 9–72 were fetched (page labels [i]–iv = Preface dated 17 Feb 1835, signed JS, Oliver Cowdery, Sidney Rigdon, F. G. Williams; [5]–64 = the seven "Lectures on Faith" ("Lecture First" … "Lecture Seventh") with their question-and-answer sections). The rest of the 1835 D&C (revelations) was not fetched (modern D&C handled elsewhere).
- **Printed text** (no scribe data); delivered in the Kirtland "School of the Elders", winter 1834–35.
- **Authorship (disputed):** issued under the First Presidency's names; most scholars credit **Sidney Rigdon** as principal author/compiler of most lectures (Rigdon delivered them), with JS revising (JS's journal Jan 1835: "preparing the lectures on theology for publication"), and possible contributions from F. G. Williams, W. W. Phelps and others; Lecture 5 is sometimes assigned partly to JS. Treat as a "Rigdon-dominant, mixed" text, not a clean Rigdon sample. The Q&A ("catechism") sections are formulaic and quote scripture heavily; consider analysing them separately.
- Stripping the preface: the preface is on pages labelled [iii]–iv (JSP pages 11–12); lecture text starts JSP page 13.
- **Text file contents:** `text/doctrine-and-covenants-1835.txt` (~24,900 words) = title page, copyright line, Preface, and Lectures First–Seventh (ending on p. [74] "...whom to know is eternal life: Amen."). Remove the title page/preface (up to "LECTURE FIRST") for a lectures-only sample.
- **Scribe field artifact:** JSP lists "Wilford Woodruff" in the page-level scribe metadata for these pages (handwritten annotations in the copy imaged), so the generated scribe split labels all words "Wilford Woodruff". **The transcribed text is the printed 1835 text**, not Woodruff's writing — ignore the scribe column here.
## How the JSP data were obtained
- **Site:** https://www.josephsmithpapers.org (The Church Historian's Press). `robots.txt` → 404 (none published). No documented public API. The site is a Next.js app: every document page `/paper-summary/<uri>/<page>` embeds its data as JSON (`__NEXT_DATA__`), and the same JSON is served at `/_next/data/<buildId>/paper-summary/<uri>/<page>.json` (buildId read from the home page). That JSON endpoint was used — one request per manuscript page, single connection, ≥1.2 s between requests, generic desktop-browser User-Agent. No blocking or rate-limit responses were encountered. (A backend API at `jsp-api.pvu.cf.churchofjesuschrist.org` exists but is only reachable through the site's `/api/proxyToBackend`; not used.)
- **Fetched:** 2026-11-12. Script: `scripts/jsp_fetch.py` (queue: `scripts/jsp_queue.sh`).
- **Raw:** `raw/<uri>/pNNNN.json` = the page JSON with site chrome removed (`metaStrings`, `layoutStrings`, `env` dropped; `historicalIntro`/`sourceNotes` kept only on p0001). Contains JSP's `clearText` (reading text) and `expandedText` (diplomatic text with deletions/insertions), footnotes, per-page `scribes`, `handwriting`, image IDs, gallery (page labels).
- **Text:** `text/<uri>.txt` = reading text built from `clearText`: editorial popups, footnote markers and bracketed editorial comments removed; place/person link text kept; no page markers. `text/<uri>.pages.jsonl` = per page: page no., label, JSP page-level scribe list, and ordered segments `{scribe, js_hand, text}`. `text/<uri>.by_scribe/<Scribe>.txt` = the document's text split by attributed hand. `text/<uri>.meta.json` = title, date, JSP handwriting statement, source note, word counts by scribe.
- **Scribe attribution method:** JSP marks every change of hand with a "new scribe" note ("Oliver Cowdery handwriting ends; Scribe 3 begins.") and tags JS's own handwriting with a `josephswriting` span class. Segments are attributed by (1) the `josephswriting` class (→ "Joseph Smith Jr."), else (2) the most recent scribe-change note, else (3) the page's single listed scribe, carried forward across pages. "UNATTRIBUTED" means no hand information on that page (typically printed texts or later copies with "No handwriting information was found"). Word counts are whitespace tokens of the reading text.
- **Caveat on "hand" vs "author":** the scribe is who physically wrote the surviving page, not necessarily who composed it. For Book of Mormon / revelation manuscripts the text was dictated by JS; scribe identity matters for orthography and for scribal error/emendation, not for authorship. For letters, a scribe's retained copy (e.g., in JS Letterbook 1 by F. G. Williams) may be dictated by JS, drafted by the scribe or a co-signer (Rigdon, Cowdery, Williams), or both. Only segments in JS's own hand are *safe* JS-composition samples, and even holographs can be copies of drafts.
- **Reading-text caveat:** JSP's `clearText` silently resolves insertions and drops cancelled text; occasional overlap artifacts occur where an overwritten letter is kept (e.g., "ministring of—Aangels" in the 1832 History). Use `expandedText` in the raw JSON for diplomatic work.
