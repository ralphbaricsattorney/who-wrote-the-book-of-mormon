## Building `data/`

`data/raw` holds every source the analysis reads, as the study used it. Not included: the Church History Library
page images and the two periodicals the Cowdery texts were taken from; the fetch scripts download them. To rebuild
`data/raw` from the original sites, run the scripts in `fetch/` from the repository root in the order given in `fetch/README.md`. Each
script writes into `data/raw/<directory>` with the file names the pipeline expects, and can be restarted
after an interruption. Then check the files against the study's copies with
`shasum -a 256 -c fetch/checksums.sha256`. Two inputs are not downloads: the JSP document lists and Smith
composition notes are stored in `fetch/jsp/` and copied into place by `fetch/jsp.py`. The transcription of
the Rigdon revelations was made from the page images for this study and is not produced by the fetch scripts.
